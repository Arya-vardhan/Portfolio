During his internship at Vishnuspire (Bhimavaram, AP), Arya prototyped an automated Reverse Vending Machine (RVM) designed to incentivize municipal recycling.

When a user deposits a plastic bottle into the collection chamber, the ultrasonic and infrared sensor array identifies the object, measures dimensions, and signals the servo sorting chute to deposit the bottle into the correct storage bin while updating local tally statistics.

Embedded Controller Routine (Python)

# rvm_sensor_daemon.py - Raspberry Pi 4B
import RPi.GPIO as GPIO
import time
# Verify object presence and trigger servo chute
def handle_bottle_deposit():
    if GPIO.input(IR_SENSOR_PIN) == GPIO.LOW:
        distance = measure_ultrasonic_distance()
        if 5.0 <= distance <= 25.0:
            open_servo_chute()
            log_telemetry("BOTTLE_SORT_SUCCESS")
